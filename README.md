# Portfolio Project Value Analyzer

An automated evaluation and grading simulation tool written entirely in pure Python. This console application is designed as a college mini-project to showcase structural string processing, algorithmic rule matching, dynamic lookup maps, and composite mathematical score formulations without relying on any external packages or frameworks.

## 🚀 Key Features

- **Dynamic Complexity Scopes**: Automatically calculates a difficulty score by counting and separating key features using string list conversions.
- **Technology Point Accumulation**: Cross-references user inputs with an internal keyword weight map to calculate an accurate technology score up to 100.
- **Contextual Text-Parsing Filters**: Screens description structures to detect industrial, business, and innovation flags, dynamically scaling market relevance ranks.
- **Algorithmic Evaluation Reports**: Formulates overall rankings (`Excellent`, `Very Good`, `Good`, `Needs Improvement`) using synchronized floor divisions.
- **Smart Recommendations Engine**: Evaluates sub-scores to generate bulleted action points helping developers optimize their project's technical scope.

## 🛠️ Python Core Concepts Covered

- **Advanced String Formatting**: Real-time parsing using nested string methods (`.strip()`, `.split()`, `.lower()`).
- **List Comprehensions**: Creating clean, whitespaced code iterations in a single line to sanitize multiple user inputs simultaneously.
- **Dictionary Lookups**: Managing data point allocations dynamically using structured key-value maps (`tech_points`).
- **Control Flow & Conditional Layouts**: Implementing multi-stage logical evaluations using sequential bounds checks (`if-elif-else`).

## 💻 How to Run the Application

1. Ensure you have **Python 3.x** installed locally.
2. Save the script workspace inside a file named `project_analyzer.py`.
3. Open your terminal or your IDE run window (such as PyCharm) and input:
   ```bash
   python project_analyzer.py
   ```
4. Respond directly to the on-screen text prompts to run a complete evaluation report.
